POS Mobile Assessment App
-------------------------
How to run:
1. Ensure Flutter SDK installed.
2. Open project in Android Studio or VSCode.
3. Run `flutter pub get`.
4. Run the app (emulator or device). Database seeds on first run.
Files added:
- lib/main.dart
- lib/db/app_database.dart
- lib/models/
- lib/repository/order_repository.dart
- lib/screens/
- lib/widgets/
Notes:
- SimpleCart provider available app-wide.
- App seeds DB using provided sample data.
